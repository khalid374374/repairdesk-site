Privacy Policy – Repair Desk

HomePrivacy Policy

Last updated: October 17, 2026. Repair Desk ("the app", "we") is a Windows desktop application for phone-repair shops. This policy explains what data the app handles and how it is used.

1. Data the app handles

  • Shop data (repair tickets, customer names and phone numbers, device details, payments, settings). This data is stored locally on the user's computer. We do not upload it to our servers.
  • Account data (email address, username, license status and a device identifier). It is stored with our authentication provider, Supabase, only to sign users in, enforce licensing and limit an account to one device at a time.

2. Google user data (optional Google Drive backup)

If the user chooses to connect Google Drive, the app uses Google Sign-In (OAuth) and requests these scopes:

  • openid and email: to show which Google account is connected.
  • https://www.googleapis.com/auth/drive.appdata: to create, read and delete backup files in the app's own hidden application-data folder in the user's Drive.

How we use it: the app uploads one compressed backup file per day containing the user's shop data, keeps the last 30 days, and downloads a chosen backup only when the user asks to restore it. The app cannot access any other file in the user's Drive.

Where it is stored: backups live only inside the user's own Google Drive. The Google refresh token is stored encrypted on the user's computer and is never sent to us or to any third party.

Limited Use: The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not used for advertising, is not sold, and is not shared with any third party. No human, including the developer, can read the backups.

3. Sharing

We do not sell, rent or share personal data with third parties, except our authentication provider (Supabase) for the account data described above.

4. Retention and deletion

  • Local data stays on the computer until the user deletes the app's data folder.
  • Drive backups older than 30 days are deleted automatically. The user can disconnect at any time from Settings, which revokes access at Google. Access can also be removed at myaccount.google.com/permissions, and the app's hidden data can be deleted from Google Drive settings (Manage apps).
  • To delete an account, email us at the address below.

5. Security

Account traffic uses HTTPS. The Google token is encrypted with the operating system's secure storage on the user's computer.
