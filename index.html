What is Repair Desk?

Repair Desk is a Windows desktop application for mobile-phone repair shops. It helps a technician or shop owner register customers' devices, follow each repair's status, record payments, and keep the shop's records organized.

Why does the app use Google Drive?

Repair Desk offers an optional backup feature. If the user chooses to connect their Google account, the app saves a daily backup of the user's own shop data (repair tickets and settings) to the hidden application-data folder of the user's own Google Drive. This lets the user restore the data on another computer with the same account.

The app requests only the drive.appdata permission. It cannot see, read, or change any other file in the user's Drive. The developer has no access to these backups.
